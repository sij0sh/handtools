# Details

**Frame.** Read the target and its direct references. Identify existing rules, evidence, and unresolved questions. Distinguish requirements from preferences, facts from assumptions, and decisions from unknowns. Ask about consequential ambiguity rather than inventing rules.

**Format.** Follow the target's conventions. SKILL.md requires `name` and `description` frontmatter; AGENTS.md uses plain Markdown; prompts use plain text. Match the project's format for agent definitions, workflows, and evaluations. Surface unknown conventions.

**Instructions.** Use semantic directives for judgment, evaluative questions to challenge outcomes, and deterministic mechanics for execution, state, and verification. Make conditional rules explicit. Keep mechanical rules only when their trigger, behavioral effect, and observable outcome are clear.
